## 오늘 한 일 (요약)

### 1. 로그인 시도 제한 — 브루트포스 방어 (`bb48c79`)
공개 배포 전 마지막 보안 실위험. `LoginAttemptGuard`가 15분 창에서 두 축으로 센다:
**계정 5연속 실패**(사전 공격) 또는 **IP 합산 20실패**(계정 스프레이) → 15분 잠금.

- **잠금 확인은 BCrypt 앞에서** — 잠긴 상대에게 느린 해시 비용을 쓰는 것 자체가 CPU
  소진 표면이라, 비밀번호 검증 전에 429로 끊는다(스로틀의 "토큰 확인은 claim 앞" 계열).
- 성공 로그인은 계정 축만 리셋(IP 축 유지 — 스프레이 방어 목적). 429엔 Retry-After와
  한국어 안내가 실리고, 프론트는 무수정으로 표시.
- **인메모리 + 승격 경로 문서화** — 로그인은 api 단일 프로세스가 받으므로 프로세스
  로컬로 충분. 수평 확장 시 포트로 승격해 Redis/Postgres(토큰버킷과 같은 경로).
- 검증: 조작 가능한 Clock 유닛 4건(잠금 해제·창 만료·스프레이·성공 리셋) + Auth 8건,
  프로드 스택 E2E(nginx XFF 실경로): 오답 5회 400 → 6번째 429 → **잠금 중엔 맞는
  비밀번호도 429** → 같은 IP 다른 계정은 200.
